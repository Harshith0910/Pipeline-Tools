# Pipeline Tool
**Language:** Python 3.10 | **Libraries:** Pillow, Tkinter

A production utility designed to automate the asset import pipeline.

### Features
* **Batch Processing:** Automates resizing of texture arrays to power-of-two resolutions (Required for Unity/Unreal optimization).
* **Compression:** Implements Pillow's optimization algorithm to reduce build size.
* **Error Logging:** Real-time console logging for technical debugging.
